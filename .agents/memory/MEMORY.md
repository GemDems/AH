- [Base64 image console logging](base64-image-console-logging.md) — never console.log/JSON.stringify full request bodies that may contain base64 image data; it silently causes multi-second/minute "hangs".
- [Express error handler crash](express-error-handler-crash.md) — an Express error middleware that `throw`s after sending a response crashes the whole process; check this first when requests "hang" or intermittently die.
- [Pasted reference component ports](reference-component-ports.md) — when user says "exact 1:1 replica, don't edit anything," keep the original animation approach even if it logs harmless console warnings; don't "optimize" it away.
- [Tailwind before: transition-duration bug](tailwind-before-transition.md) — before:transition-all overwrites before:duration-* in generated CSS; use before:[transition:transform_Xms_ease] as one arbitrary value instead.
- [LiquidBadge dark-mode border artifact](liquid-badge-border.md) — dark:border-white border-black border-2 creates a visible white rectangle in dark mode on dark backgrounds; remove all border classes for a clean badge appearance.
- [overflow-hidden clips filter blur](overflow-hidden-clips-blur.md) — any ancestor with overflow:hidden clips filter:blur() glow; remove overflow-hidden from the ancestor (or scope it narrowly) to let outward glow show.
- [Conic glow layer h-full sizing](conic-glow-layer-sizing.md) — glow layers with h-full w-full inherit parent height; if parent is sized by non-absolute children (e.g. a 56px input), glow layers become same size as input and glow disappears. Fix: give the poda wrapper an explicit height (e.g. h-[70px]) so h-full resolves to the intended larger value.
- [Drizzle timestamp string crash](drizzle-timestamp-string-crash.md) — a JSON date field forwarded to a Drizzle timestamp() column without `new Date(...)` crashes with "value.toISOString is not a function" only when that field is actually set.
